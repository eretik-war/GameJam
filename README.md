# GameJam

Основа 2D-игры: TypeScript, PixiJS 7.4.3 и автономная HTML-сборка. Тема и механика геймджема ещё не выбраны.

```sh
git clone https://github.com/eretik-war/GameJam.git
cd GameJam
npm ci
npm run check
npm run dev
```

Нужны Git и Node.js 22+; CI проверяет Node.js 24.16.0. Игра открывается на http://127.0.0.1:4173. На Windows при блокировке npm.ps1 используйте npm.cmd.

**С 2026-10-30 по указанию пользователя работаем только локально.** GitHub, отправка и автоматическое получение приостановлены до отдельного возобновления. Не запускать сетевые sync-команды и установку расписания. Актуальный режим и справочник команд находятся в инструкции совместной работы ниже.
