# GameJam

Прототип 2D-игры: TypeScript, PixiJS 7.4.3 и автономная HTML-сборка. Реализованы девять боёв с катсценами, наземные камеры и щитовики, воздушная поддержка, инвентарь из 12 типов предметов и диалоги боя. Окончательный геймдизайн и площадка публикации ещё не утверждены.

```sh
git clone https://github.com/eretik-war/GameJam.git
cd GameJam
npm ci
npm run check
npm run dev
```

Нужны Git и Node.js 22+; CI проверяет Node.js 24.16.0. Игра открывается на http://127.0.0.1:4173. На Windows при блокировке npm.ps1 используйте npm.cmd.

**По умолчанию работаем локально; автоматическое получение и отправка выключены.** 2026-10-31 отдельно разрешена разовая синхронизация всех локальных доработок с GitHub и обновление документации. После операции действует прежняя пауза; новая синхронизация требует прямого поручения. Расписание не включать. Актуальный режим и справочник команд находятся в инструкции совместной работы ниже.
