# Проверка инвентаря — 2026-10-30

Активная версия 0.1.0, PixiJS 7.4.3. Проверено в headless Chromium 148 с программным WebGL/SwiftShader на Windows. На физических телефонах/Safari/Firefox проверка не выполнялась.

## Модель

Пять новых сценариев входят в общий запуск `npm test`: пустой старт/уникальная тройка/однократное получение; переносы и обмены между всеми областями без потери ID; запрет боя и некорректных ячеек с атомарностью; полные карманы и продолжение без награды; сбой генератора и независимые ID при общей неизменной Info. Существующие NPC и противники также проверяются общим набором.

## Браузер

| Конфигурация | Способ запуска | Результат |
|---|---|---|
| 1440×900 | локальный HTTP | passed |
| 1280×720 | изолированный file:// | passed |
| 320×568 | изолированный file://, touch | passed |
| 390×844 | изолированный file://, touch | passed |
| 568×320 | изолированный file://, touch | passed |
| 844×390 | изолированный file://, touch | passed |

Во всех конфигурациях проверены: старт с пустым инвентарём и боем, скрытые карманы и три заблокированных слота; три различных награды; Escape не закрывает обязательный выбор; resize не меняет награду; выдача одной копии; перенос и обмен; перемещение Enter; обратный переход к бою; пустой старт после reload. Проверены реальные mouse/Chromium touch inputs. В низком landscape для удалённых друг от друга ячеек используется выбор двумя касаниями с прокруткой. В 320×568 и 390×844 выполнен touch drag. Размер drop-целей ≥64 CSS px, горизонтального overflow нет; на широком экране карманы не перекрывают область противников.

Дополнительно в desktop HTTP: отпускание вне ячеек, Escape и resize во время drag без потери предмета/оставшегося ghost; заполнение всех карманов через UI; три отключённые награды и переход к подготовке; освобождение кармана в активный слот и следующая награда; прежние команды горения/хода/урона и save/load противников сохраняют инвентарь.

Ошибок pageerror/console.error и внешних runtime-запросов нет, включая закрытие страницы. Изолированный HTML открывается без соседних исходников/ресурсов. Raw: [inventory-browser-results.json](inventory-browser-results.json). Скриншоты: inventory-combat.png, inventory-reward.png, inventory-preparation.png, inventory-mobile-320.png, inventory-landscape-844.png.

При совместной работе дополнительно проверена совместимость с параллельными hover-карточками в общей папке. Эти карточки не входят в реализацию инвентаря.

## Исправление области UI — 2026-10-30

По прямому уточнению пользователя восстановлены исходные шапка, тема, поле с фигурами противников, выбор, боковая панель и кнопки из 2d7c00a. Из доработки инвентаря убраны собственная шапка/номер стадии, декоративное поле/разметка боя, область-заглушка персонажа и сворачивание тестовых команд. Остаются отдельный блок инвентаря, кнопка стадий и обязательный выбор награды. Геометрия фигур/подписей/областей выбора возвращена к исходной; локальные hover-подключения другого чата сохранены.

Повторно проверены HTTP: 1280×720, 1440×900, 320×568, 390×844, 568×320, 844×390; отдельно прямой file://. Во всех размерах: оригинальный заголовок и пять команд противников, отсутствие добавленного оформления всего экрана, пустой боевой старт, уникальная тройка наград, выдача предмета, перенос/обмен, блокировка боя, отсутствие пересечения с противниками/горизонтального overflow, drop-цели ≥64 CSS px. Команды горения/хода/сохранения/загрузки противников работают и не меняют инвентарь. Ошибок браузера нет. Модель предметов и правила наград не менялись.

Актуальные доказательства суженного интерфейса: [inventory-scope-results.json](inventory-scope-results.json), inventory-scope-desktop.png, inventory-scope-mobile-320.png. Скриншоты выше относятся к первоначальному оформлению и сохранены как история проверки.
