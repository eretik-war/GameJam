# Проверка героя — 2026-10-30

Desktop Chromium/SwiftShader на Windows. Проверены HTTP 1440×900 и прямой file:// 1280×720.

- Три исходных PNG декодированы с прозрачностью; общий размер и UV-область совпадают между кадрами. Пропорции/ноги стабильны, герой находится в указанной пользователем области справа от карманов.
- Тем же экспортированным builder проверены границы цикла: через 150 мс кадр 1, 170 мс кадр 2, 340 и 499 мс кадр 3, 501 мс снова кадр 1. Общая длительность — 500 мс, кадров — три, autoUpdate через общий тикер выключен.
- На реальном AnimatedSprite сцены измерены последовательные возвраты к первому кадру; полные циклы близки к 500 мс с дискретностью кадров браузера. Начальный неполный интервал при возобновлении не учитывается.
- Перерисовки по команде хода сохраняют тот же экземпляр героя. Награда → перенос в слот → бой работают; положение/размер героя задаются относительно той же неизменной зоны.
- Ошибок pageerror/console.error, в том числе при закрытии страницы, нет. Оригиналы PNG не редактируются.

Raw: [hero-idle-results.json](hero-idle-results.json). Вид: hero-idle-combat.png, hero-idle-preparation.png. Проверка измеряет анимацию и визуальное размещение; новые боевые механики героя не добавлены.
