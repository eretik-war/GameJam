# Карточка героя — 2026-10-30

По поручению пользователя герой получил карточку на общем HoverCardController: 500 мс непрерывного наведения, отмена при уходе, Escape и открытие нажатием. Положение и масштаб героя/сцены сохраняются, трёхкадровая анимация продолжается во время показа.

Владелец данных — presentation/entity-hover-cards.ts:createHeroHoverCard. При наличии боевого Hero здоровье, щит, состояние и эффекты берутся из существующего createNPCView; экипировка, карманы, стадия и доступность переноса — из InventorySession. Числа и размеры слотов в UI не копируются. В совместимой локальной сцене без модели Hero остаются данные инвентаря. Никакие новые боевые правила и параметры этой карточкой не создаются.

Опубликованный вариант основан на a82415c с настоящим session.hero: в main.ts заменён resolver и добавлено открытие нажатием на heroAnchor. Локальная объединённая сцена использует общие sceneBounds/bindSceneCard для Pixi-героя и противников. Анимация подключается один раз, повторные render не добавляют обработчики.

Проверка Chromium/SwiftShader: HTTP 1440×900 и изолированный file:// 1280×720; на 499 мс скрыто, на 500 мс показано. Проверены уход/Escape, показ экипировки 0 / 3 → 1 / 3 после реального переноса, карманы, бой/подготовка, регрессия карточки врага, продолжающаяся анимация и неизменность координат/масштаба/размеров/прокрутки. В версии с боевым Hero показаны 1000 HP и 20 щита из модели; debug-команда уменьшает HP до 1, и уже открытая карточка обновляется. Ошибок console.error/pageerror нет.
