# Карточка героя — 2026-10-30

По поручению пользователя общий механизм карточек подключён к герою на сцене. Непрерывное наведение 500 мс открывает карточку; уход до задержки отменяет её, Escape закрывает. Нажатие на героя открывает ту же карточку. Герой сохраняет своё положение, масштаб и трёхкадровую анимацию; отдельные окна или место в раскладке не создаются.

Владельцы: main.ts:sceneBounds/bindSceneCard — общая Pixi-привязка героя и противников; presentation/entity-hover-cards.ts:createHeroHoverCard — представление. Карточка читает InventorySession: заполнение активных слотов и карманов, текущую стадию и доступность смены экипировки. Размеры слотов берутся из модели. Боевых параметров героя в текущей модели нет; выдуманные здоровье/урон/броня и новая игровая сущность не добавлялись. Повторное наведение всегда получает актуальные значения.

Проверка настольного Chromium/SwiftShader: HTTP 1440×900 и изолированный file:// 1280×720. На 499 мс карточка скрыта, на 500 мс показана; уход/Escape работают. После награды и переноса предмета в активный слот отображается 1 / 3 и стадия подготовки; после начала боя — стадия боя с той же экипировкой. Карточка противника продолжает работать. Анимация героя меняет кадр во время показа, координаты/масштаб героя, размеры сцены/документа и прокрутка не меняются. Ошибок pageerror/console.error нет.

Локальный verification-helper: work/test-hero-hover.cjs. Raw и скриншоты локальной объединённой сцены: builds/hero-hover-results.json, hero-hover-combat.png, hero-hover-preparation.png. Сборки содержат локальных NPC, поэтому эти изображения не публикуются вместе с карточкой. Общие проверки перед отправкой — npm run check; публикация только собственных изменений из отдельной ветки без локальных commits NPC.
