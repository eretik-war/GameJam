## Адаптация

- Герой использует тот же Enemy-владелец HP/щита/статусов, собственный неизменяемый Info и роль Hero. Визуальные данные старого JSON не переносились в игровой Info; анимация остаётся у существующего renderer.
- createCombatantView предоставляет одну карточку/боевые значения героя и врагов; createNPCView добавляет отдельную модульную композицию. createCombatIndicators переиспользуется у героя и камер.
- Выбор ближайшей колонки переведён с индексов старого массива пяти юнитов на x настоящего spawn-point. Порядок массива и наличие резерва не меняют допустимые цели; резерв не атакует.
- Величины исходного боя сохранены. Урон героя и ответа врагов нормализованы в замороженные TypeCombatParameter/Value; бонус ItemInfo применяется один раз. Разрешены карманы и экипировка в бою, как в a82415c.
- Save v2 дополняется необязательным hero: параметры, статусы и ID восстанавливаются до замены сессии. Старые файлы без hero получают исходного героя, без сброса противников/размещений. Смерть героя блокирует атаки; переполнение хода проверяется до изменения состояния.
