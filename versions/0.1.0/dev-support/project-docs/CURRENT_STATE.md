Готовая задача описывается явно: `task register` → `task ready` → `plan` → `publish --plan`. Разобранный конфликт закрывается одним `publish --continue`: оформление, проверка и отправка в одном вызове; `resolve` остаётся локальным. Подтверждение проверки привязано к commit, дереву, профилю, версии инструмента и среде и переиспользуется только в цепочке операции. main/origin-main; частная неопубликованная история по-прежнему требует явного списка commits. Общая пауза/lock, изолированный candidate, до трёх повторов при гонке, readback по наличию commit в удалённой истории. Checkpoint при сбое сохраняется. Журнал, реестр задач и планы хранятся в общем Git-каталоге; авторы и Task/Sync-Operation — также в commits.
