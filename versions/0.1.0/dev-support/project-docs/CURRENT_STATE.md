Актуально на 2026-10-31. Активная версия — 0.1.0; пути — PROJECT_MANIFEST.json. Только компьютерная версия.

## Цель и разрешения

Пользователь поручил объединить обе стороны, проверить и отправить **все существующие локальные доработки нескольких чатов вместе с документацией**. Входящая порция просмотрена: `638d5f9` (воздушная поддержка/щитовики) и дополнительный push `947d6b7` (цветные роботизированные ножки). Исходные 79 изменённых/новых файлов сохранены checkpoint `0778316`; неопубликованные предки просмотрены и одобрены. Интеграция выполнена через проектный sync, исходники не заменялись чужой копией.

Разрешена только эта ручная синхронизация. После публикации — локальная пауза; автоматическое получение/отправка и Windows-расписание не включаются. Канонический режим — [GITHUB_WORKFLOW](GITHUB_WORKFLOW.md#auto-push), обязательный вход — [SYNC_TOOL](../../../../SYNC_TOOL.md). Точный итог отправки/удалённый SHA — локальный журнал `.git/gamejam-sync`, не обещание из этого документа.

## Объединённый результат

- Девять боёв: fight-1…3 → intro → fight-4…6 → interlude → fight-7…9 → outro → finale или плавный restart. Кампания выбирает из общего совместимого каталога, рост до пяти ground/air-точек; шаблоны encounters не задают фиксированный состав прохождения — [SCENE_SEQUENCE](SCENE_SEQUENCE.md).
- Четыре камеры с индивидуальными атаками и цветными роботизированными ножками, четыре типа воздушной поддержки, два наземных щитовика. Общие Info/параметры/ауры/провокация сохранены — [ENEMIES](ENEMIES.md).
- 12 типов предметов: линзы, пассивные модули, отдельное семейство item.09–12; общий пул наград и renderer, предоставленные PNG иконок — [INVENTORY](INVENTORY.md), [COMBAT_ITEMS](COMBAT_ITEMS.md).
- Анимированный герой, компактные карточки, прозрачные PNG статусов, диалоги первого боя и реплики при уроне — [BATTLE_DIALOGUE](BATTLE_DIALOGUE.md), [CODE_MAP](CODE_MAP.md).

## Решения интеграции и рабочие файлы

Шесть конфликтов разрешены с сохранением обеих сторон: RESOURCE_REGISTRY, enemy.ts, session.ts, view.ts, campaign.test.ts, domain.test.ts. TypeEnemyParameter остаётся отдельным enum; SupportParameters добавлены без второй копии enum. Ответные атаки используют собственный AttackInfo и ауру урона, уклонение/сопротивление/перенос эффектов не потеряны. Карточки показывают поддержку и провокацию через общий view.

Две несовместимости выявлены проверками и исправлены: стабильный `attack.test` восстановлен в общем attack-каталоге с прежним уроном щитовиков; фабрика боя выбирает реально атакуемую цель через CanTarget. Тест роста/случайного каталога учитывает оба слоя и выводит лимит из spawnPoints. Актуализирован verify-campaign для пяти точек и повторного выбора цели после разрушения щита. Предметный QA использует явно заданный совместимый camera-fixture для эффектов, а награды получает настоящей победой.

Рабочий набор после merge: общие входные документы и индекс, ENEMIES/SCENE_SEQUENCE/CODE_MAP/RUN_COMMANDS, этот статус/архив, attack.ts/test-attack.json, campaign.ts, tests/combat/campaign, verify-campaign и verify-combat-item-extension. Locks, vendor, версия, сохранения и старые копии не менялись. Дополнительная документация проверки — [SYNC_INTEGRATION](../qa/SYNC_INTEGRATION.md).

## Ограничения и следующий шаг

Полное сохранение прохождения/инвентаря отсутствует; debug save/load — только текущий бой. Первый бой может содержать единственный воздушный тип поддержки: это следствие общего совместимого случайного каталога, не новая фиксированная постановка уровня. Propeller-анимация не добавлялась. Старые verify-healers/verify-guards содержат прежнюю цепочку; для актуального маршрута использовать verify-campaign. Сюжетные тексты и окончательный баланс остаются тестовыми.

Следующий шаг — оценка объединённого прохождения пользователем; новые доработки и сетевые операции по отдельному поручению.
