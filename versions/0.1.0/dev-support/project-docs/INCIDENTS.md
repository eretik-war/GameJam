# Инциденты

## QA-001 — координаты новой сцены, 2026-10-30

При быстром нажатии после DOM-действия новые контейнеры ещё не получили world transforms до следующего кадра: выбор по canvas не срабатывал. После перестроения сцены добавлен немедленный renderer.render. Проверка: выбор обоими способами после изменения состояния, мышь и touch в browser-results.json. Исправлено в starter до передачи.

## QA-002 — visibility после destroy, 2026-10-30

При закрытии страницы pagehide уничтожил приложение, затем visibilitychange попытался остановить уже освобождённый ticker. Добавлены disposed guard, снятие обработчиков и отдельная обработка BFCache; ResizeObserver тоже проверяет disposed. QA теперь проверяет pageerror и после закрытия контекста, сохраняя копии массивов ошибок. Финальная проверка не имеет ошибок. Исправлено до передачи, пользовательских сохранений не затрагивало.
