# Принятые решения

- D001, 2026-10-30: переносимая папка с локальным vendor и project-owned tools вместо live Foundation/builder linkage. Причина — передача другому человеку без чужих абсолютных путей. Общие знания перенесены с provenance; registry не меняется.
- D002: PixiJS7.4.3 — проверенная версия семейства, точный vendor hash; обновление на новый major только отдельной миграцией. TypeScript выбран для строгих enum и проверки доменов.
- D003: Parameters — массив объектов Type/Value, RestoreParameter — enum цели/дельта; NPC.ChangeParameter перебирает записи. Info и вложенные записи заморожены, экземпляры независимы. В примере HP0..база; armor/damage неотрицательные. Это границы демо, будущий баланс определяет игра.
- D004: технический starter вместо копии merge-игры Forest Alchemy. Жанр/контент джема неизвестны; принятые mobile-размеры и справочник геометрии перенесены, арт/музыка/merge-правила не копировались.
- D005: предметное чтение и базовый onboarding разделены по прямому поручению пользователя; расширение задачи идёт через индекс.
