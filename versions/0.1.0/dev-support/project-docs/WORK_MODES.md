# Режимы чтения и проверки

Общее знакомство читает базовый набор из READ_FIRST. Конкретное направление читает короткий вход/индекс/раздел CODE_MAP и только затронутую область. При расширении области вернуться к индексатору. Canonical смысл: ../standards/PROJECT_READING_RULES.md относительно project-docs.

Документация/текст: проверить ссылки/значения и нужный экран. Модель/сохранения: Info/параметры/общие view, типизация и содержательные тесты. UI/рендер: Pixi/мобильные правила, браузер/resize. Сборка: engine lock, инструменты, переносимость и прямой offline запуск. Платформа: только после выбора SDK/цели читать нужный platform contract.

Объём проверки зависит от риска, а разрешение — от пользователя. Нельзя пропускать обязательный применимый контракт из-за узкого режима. Не перечитывать unrelated историю/зависимости.
