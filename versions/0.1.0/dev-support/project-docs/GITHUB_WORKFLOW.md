# GitHub и совместная работа

Источник репозитория — PROJECT_MANIFEST.json: [eretik-war/GameJam](https://github.com/eretik-war/GameJam), общая ветка main. Репозиторий хранит исходники, данные, ресурсы и locks. Offline HTML воспроизводится локально; GitHub-репозиторий не означает deploy игры.

## Активный режим: только локально

Пользователь приостановил GitHub и автопроверку 2026-10-30. До нового прямого поручения **не выполнять fetch/pull/push, ls-remote, опрос проекта GitHub/CI, автоматическое получение и удалённую итоговую проверку**. 2026-10-31 отдельно разрешена пробная публикация готового результата этого чата: модульные NPC/бой, связанные ресурсы, единый sync-инструмент и документация. Это разовая ручная операция; прежняя автоматическая отправка и фоновое расписание не возобновляются. Завершение других задач и наступление следующего дня не снимают паузу.

Локальная разработка, сборка и проверки продолжаются. Точечные status/diff и адресные checkpoints допустимы для сохранности; обязательной Git-строки в каждом сообщении нет. Чужие незавершённые и несогласованные изменения не отправлять; готовые NPC включены в прямое поручение выше. Запреты force push/reset --hard/clean/автоматического stash/rebase сохраняются. Новая версия, deploy, публикация игры и удаление старых копий — отдельные решения.

На этой машине задача Windows GameJam-Sync-95E2E963735A отключена. В общем Git-каталоге стоит gamejam-sync/paused.json: сетевые команды скрипта блокируются во всех связанных worktree. Прямой git/gh технически не перехватывается — соблюдать разрешение пользователя. Иные машины этим локальным маркером не управляются.

## Единый скрипт

Перед **любой задачей** обязательно прочитать [SYNC_TOOL.md](../../../../SYNC_TOOL.md). Само чтение не запускает скрипт. Это каноническая инструкция команд, request JSON, результатов и исключений; не поддерживать второй набор ручных Git-команд в чатах. Выполнение перенесено в tools/sync.mjs; агент задаёт действие, задачу и согласованный состав, затем читает краткий результат. Полный журнал и diff-пакет остаются на диске.

Пользователь принял 2026-10-31:

- точечное чтение, краткое актуальное состояние, подробности в отчётах;
- одну общую интеграцию с просмотром всей входящей порции;
- публикацию согласованной готовой порции;
- автоматический merge без конфликтов с проверкой результата; при конфликте — остановку и отчёт.

Скрипт сравнивает историю и содержимое Git, а не дату файлов или «кто последний нажал push». При гонке обновления повторяет получение/merge/проверку ограниченное число раз. После публикации проверяет наличие отправленного commit в наблюдаемой удалённой истории; более поздний commit товарища допустим. Это не подтверждает, что другая машина уже обновила свою папку.

## Возобновление

Только после прямого поручения пользователя выполнить `npm run sync:resume`, затем нужное compare/pull/push по инструкции. resume локально снимает маркер и не включает Windows-расписание. Автоотправку каждой задачи самостоятельно не восстанавливать.

В общей папке могут остаться незавершённые/частные изменения. Публикация требует точных файлов и явного одобрения ранее неотправленных commits; approval-required не обходить одобрением всего списка без просмотра. При конфликте править файлы сохранённого workspace и вызывать resolve; команда завершает только локальную интеграцию. Текстовый merge без конфликтов не доказывает игровую совместимость — общий результат проверяется.

## Подключение товарища

На его машине нужна собственная копия проекта, Node.js 22+, Git и личные user.name/user.email. Для отправки — собственная авторизация GitHub; владелец приглашает rgweh как collaborator, товарищ принимает приглашение. Не копировать чужие credentials. После клонирования установить зависимости через npm ci и выполнить npm run check; запуск — npm run dev. Эти сетевые действия выполняются при согласованном подключении, не в текущей локальной паузе.

Оба участника используют одну версию скрипта/инструкции из проекта. Git хранит авторство commits; новые checkpoints/merge получают Task и Sync-Operation. Локальные операции, отказы, проверки и SHA записываются в общий Git-каталог каждой копии; журнал не коммитится, чтобы сам не создавать конфликтующий общий файл.

## Автоматическое получение Windows

Сейчас выключено. Включать отдельно по поручению: npm run sync:auto:install; локальное состояние — sync:auto:status; удалить задачу — sync:auto:remove. Установка не снимает сетевую паузу. Прежний фон раз в пять минут ограничен чистым main и fast-forward: без автообъединения divergence, запуска присланного кода, commit или push. Обычный явный pull использует новый проверяемый merge-процесс.
