# Противники и статусы

Новые модули: src/enemies. EnemyInfo объединяет базовые Health/Shield и imageUrl (GIF/data URI); Pixi/DOM принадлежат renderer. Атаки пока не реализованы. Универсальный Enemy хранит независимые текущие параметры и статусы; урон сначала расходует щит, затем здоровье. Ноль здоровья означает смерть.

IStatusEffect описывает фиксированное поведение. Каждый эффект — отдельный скрипт. Burning — демонстрационное горение, 3 урона за тик; баланс примера не утверждает окончательный набор эффектов. Экземпляр статуса хранит длительность; повторное наложение складывает её. Начало общего хода обрабатывает статусы в порядке первого наложения, после каждого тика уменьшает срок, удаляет истёкшие. Смерть прекращает обработку и снимает статусы. Наложенные после начала хода эффекты срабатывают со следующего начала.

Будущий порядок: статусы → атака игрока → атаки живых противников. Текущий экран содержит только тестовые команды урона/горения/начала хода. GIF не предоставлена, используется прежняя фигура; imageUrl можно задать встроенным data URI для offline. Новые сохранения schemaVersion 2 используют отдельный ключ gamejam.enemies.v2; прежние NPC-сохранения остаются нетронуты и не мигрируют автоматически.
