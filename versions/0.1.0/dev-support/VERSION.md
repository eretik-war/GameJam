# История версий

## 0.1.0 — 2026-10-30

Локальная доработка по поручению пользователя: четыре модульных наземных стрелка из предоставленных камер и ножек. PNG камер разделены с сохранением исходной прозрачности; отдельный VisualInfo хранит сокеты и модули. Пять прежних мест стали типизированными точками спавна: верхние две воздушные, правая и нижние две наземные. В новой сцене три врага, воздушных типов пока нет. Сохранения v2 сохраняют typeId и размещение; старые составы из пяти врагов не теряются. Проверки — [MODULAR_ENEMIES](qa/MODULAR_ENEMIES.md). Commit/push этой доработки не поручен: пользователь указал «пока локально».

По прямому поручению пользователя создан переносимый GameJam starter: локальный PixiJS7.4.3, TypeScript, NPC/параметры, документация для человека и нейронки, сборка standalone HTML, тесты и HTTP-preview. Общие документы получили режимы чтения и параметрический контракт. Версия игры/её геймдизайн ещё не разрабатывались сверх технического примера.

В рамках 0.1.0 добавлены герой test1 слева и пять Enemy справа с выбором нажатием, белой обводкой, полосками HP/щита и иконками статусов. Изображения перенесены в корневой assets/images; Enemy/Attack описаны JSON-ассетами, атака пока без выполнения. Горение использует testeffect. Сцена объединена с инвентарём и hover-карточками, отправлена f8ecd73. Проверки: 12 тестов модели, 8 Git-тестов, typecheck, offline build, validate и desktop browser. Новая версия не создавалась.
