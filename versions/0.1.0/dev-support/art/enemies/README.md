# Исходники модульных камер

Предоставлены пользователем 2026-10-30: camera-source.png — четыре камеры, leg-source.png — общий модуль ножек, assembly-reference.png — пропорции сборки. PNG уже содержат alpha. Изображения не генерировались и не перерисовывались. Авторство/лицензия не сообщены; используем как предоставленные локальные тестовые ассеты.

Повторить разделение: в корне проекта запустить `./tools/extract-enemy-parts.ps1`. Новые исходники можно передать через `-CameraSource` и `-LegSource`. Скрипт сохраняет пиксели/alpha, вырезает камеры на одинаковый canvas 232×164, ножки — 211×480. Координаты и alpha-bounds находятся в extraction.json. Общий canvas учитывает более низкое расположение жёлтой камеры и не обрезает её нижний край.

Runtime PNG находятся в корневом assets/images/enemies. Модуль ножек в исходнике имеет две чёрные опоры: на чёрном фоне вложения одна из них почти не видна. Обе сохранены. Модуль масштабируется 0.725 и соединяется с underside через собственный pivot; пропорции повторяют assembly-reference. Числа принадлежат assets/enemies/camera-visuals.json. Пустые top/rear/lens — точки для будущих модулей, текущее поручение их не заполняет.

`node tools/preview-enemies.mjs` собирает preview из того же resolver и DOM-компоновщика, что используются игрой. PNG превью создаёт browser verifier, вручную повторять сборку в графическом редакторе не требуется.
