# Исходники иконок статусных эффектов

Предоставлены пользователем 2026-10-31 в виде вертикальной ленты из трёх эффектов:
1. Верхний — **горение** (`burning`, розовая вспышка огня).
2. Средний — **ослепление** (`blindness`, жёлтый глаз с перечёркиванием).
3. Нижний — **оглушение** (`stun`, сине-голубые спирали).

## Обработка и разделение

- Фон исходника — прозрачный.
- Удалён субпиксельный шум с alpha ≤ 2.
- Каждое изображение вырезано строго по габаритам (bounding box) непрозрачной области:
  - `burning`: `X: [36, 246]`, `Y: [2, 263]`, размер **210×261** px.
  - `blindness`: `X: [24, 294]`, `Y: [414, 589]`, размер **270×175** px.
  - `stun`: `X: [44, 264]`, `Y: [747, 943]`, размер **220×196** px.

Координаты зафиксированы в `extraction.json`. Runtime-файлы сохранены с поддержкой прозрачности (PNG):
- `assets/images/fire.png` (заменяет прежний `fire.jpg`)
- `assets/images/blindness.png` (заменяет прежний непрозрачный `blindness.png`)
- `assets/images/stun.png` (заменяет прежний `stun.jpg`)

В игре эффекты отображаются над полосками HP/щита каждого участника боя через `createCombatIndicators` (`presentation/combat-indicators.ts`) со скейлом до 16×16 px с сохранением пропорций и прозрачности.
