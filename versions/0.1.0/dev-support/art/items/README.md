## item.09–12: изображения пользователя, не старые линзы

По прямому уточнению пользователя новое семейство имеет отдельные item-combat-*.png: голубой IMG_5547 → item.09, розовый IMG_5549 → item.10, золотой IMG_5546 → item.11, бирюзовый IMG_5548 → item.12. Прикреплённые оригиналы сохранены побайтно в combat/. Они отличаются от исходников прежних модулей; подмена похожими картинками не допускается. tools/prepare-combat-item-icons.py только обрезает прозрачные поля и пропорционально уменьшает до 128×128 с полем 4 px, сохраняет прозрачность и внутренние детали, без генерации/перекраски. Предоставленный alpha не заменяется чужой маской; это отдельные изображения. SHA, crop, размер, путь и обработка — combat-icons-extraction.json и RESOURCE_REGISTRY. Все исходные линзы и модули item.01–08 оставлены без изменений. Названия/механики нового семейства этим поручением не менялись. Автоматический просмотр изображений был недоступен (401); сопоставление проверено по доминирующему цветовому тону пикселей и SHA исходных файлов. Общий renderer подтверждён в Chrome HTTP/file: новая картинка одинаковая в награде, карманах и экипировке.
