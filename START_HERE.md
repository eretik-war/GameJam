# Как начать человеку

## Сначала посмотреть

Если вы получили готовую сборку, откройте [готовый HTML](versions/gamejam_0.1.0-offline.html) двойным кликом в обычном браузере с WebGL. Для этого не нужны сервер, Node.js, интернет или папка Foundation. После клонирования GitHub сначала выполните npm ci и npm run build:offline — HTML не хранится в Git. Выберите одного из двух NPC, завершите ход, восстановите здоровье, сохраните и загрузите. Второй NPC не должен измениться.

## Начать разработку

1. Установите Git и клонируйте проект: `git clone https://github.com/eretik-war/GameJam.git`. Или скопируйте **всю папку GameJam** для локальной работы без синхронизации. Путь C: не зашит в runtime; поле root манифеста — запись места создания. Не требуется воспроизводить чужой диск/имя пользователя.
2. Установите Node.js 22+ (проверено на 24.16.0) с npm через [официальную страницу](https://nodejs.org/en/download). Откройте новый терминал. node --version и npm --version должны работать. Редактор — любой с поддержкой TypeScript.
3. Откройте терминал **в корне GameJam**, где package.json. На этой машине зависимости уже установлены. После переноса на другую ОС/архитектуру или без node_modules выполните npm ci; для восстановления пакетов нужен интернет. Не используйте npm install без причины менять lock. npm.cmd помогает в PowerShell, если запуск npm.ps1 запрещён политикой.
4. Выполните npm run check, затем npm run dev. Откройте http://127.0.0.1:4173. После правки src обновите страницу — сервер пересоберёт пример. Для остановки Ctrl+C. Если порт занят, задайте GAMEJAM_PORT=4174 средствами своей оболочки.
5. npm run build:offline создаёт новый одиночный HTML в versions. Его можно передать отдельно. Исходники находятся в versions/0.1.0/src; данные/модель/представление разделены.

Полные команды и устранение проблем: [RUN_COMMANDS](versions/0.1.0/dev-support/project-docs/RUN_COMMANDS.md). Введение в наш процесс: [WORKFLOW](versions/0.1.0/dev-support/project-docs/WORKFLOW.md). Сведения о сборке: versions/0.1.0/dev-support/build-manifest.json.

## Обмен изменениями

**Сейчас GitHub приостановлен по указанию пользователя от 2026-10-30.** Работаем только локально; автоматическое получение отключено. Не запускать sync:pull/sync:push и не устанавливать автообновление до отдельного возобновления. Порядок — [GITHUB_WORKFLOW](versions/0.1.0/dev-support/project-docs/GITHUB_WORKFLOW.md#auto-push).

## Первое сообщение нейронке

Для общего знакомства: «Ознакомься с проектом в этой папке. Начни с AGENTS.md и READ_FIRST_LATEST_PROJECT.md. Пока ничего не меняй».

Для предметной работы: «Этот чат для работы над инвентарём. Прочитай краткий вход и нужную область по индексу, соблюдай Info и типизированные параметры; остальные области дочитывай только при необходимости. Реализуй …».

Перед параллельной работой назначьте владельцев файлов/подсистем. Не редактируйте один файл одновременно; общие enum, Info, save schema и пакетные зависимости согласуйте до объединения. Папки версий и копии не заменяют договорённость о владельце изменений.
